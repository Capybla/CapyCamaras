Solo añade fuentes públicas cuyo uso esté permitido. Se guardan únicamente en este navegador.

Las cámaras de la DGT publican fotogramas fijos que el organismo renueva periódicamente, no vídeo continuo. Las cámaras municipales de València se publican como página de visualización: se muestran incrustadas y, si existe imagen directa, se carga sola con refresco automático. Las fuentes mundiales proceden de catálogos públicos (Fintraffic, Transport for London, Ayuntamiento de Madrid, Caltrans) y se activan a mano. Este visor no intenta saltarse restricciones de los proveedores (hotlinking, X-Frame-Options, autenticación): cuando una fuente no se puede mostrar, la tarjeta se conserva con el motivo y un enlace para abrirla fuera.
